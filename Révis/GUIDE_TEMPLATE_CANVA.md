- **"Présentation technique"**
- **"Présentation projet web"**
- **"Présentation développeur"**
- **"Présentation startup moderne"**
- **"Présentation portfolio tech"**
- **"Présentation projet étudiant"**

### Styles recommandés :
- **Moderne et minimaliste** (fond sombre avec dégradés)
- **Tech/Startup** (couleurs vives sur fond sombre)
- **Professionnel moderne** (bleu/gris avec accents colorés)
- **Évite** : Templates trop colorés/enfants, trop corporate, trop formels

## 📋 Structure à adapter (8 diapositives)

### Diapositive 1 : Titre
- **Titre principal** : "Générateur de Séances d'Entraînement Badminton"
- **Sous-titre** : "Application web personnalisée"
- **Ton nom** + BUT MMI 3ème année
- **Date**

### Diapositive 2 : Contexte
- **Titre** : "Pourquoi ce projet ?"
- **Points clés** : Besoin de séances adaptées, difficulté à créer des entraînements équilibrés

### Diapositive 3 : Solution
- **Titre** : "Notre Solution"
- **Schéma simple** : Formulaire → Génération → Résultat → PDF
- **Points clés** : Génération automatique, personnalisation, export PDF

### Diapositive 4 : Technologies
- **Titre** : "Stack Technique"
- **Liste** : Next.js 16, React 19, TypeScript, Zod, Tailwind CSS, Framer Motion, jsPDF
- **Design** : Logos ou icônes des technologies (si disponibles)

### Diapositive 5 : Architecture
- **Titre** : "Comment ça fonctionne ?"
- **Schéma de flux** : Formulaire → Validation → API → Génération → Affichage
- **Code couleur** pour différencier les étapes

### Diapositive 6 : Fonctionnalités
- **Titre** : "Fonctionnalités Principales"
- **Liste à puces** avec icônes : Génération intelligente, Filtrage solo/partenaire, Ajustement intensité, etc.

### Diapositive 7 : Points Techniques
- **Titre** : "Choix Techniques"
- **Points** : Validation double, Séparation des responsabilités, API Route, TypeScript, Données centralisées

### Diapositive 8 : Conclusion
- **Titre** : "Démonstration & Perspectives"
- **Points** : Démonstration, Perspectives d'évolution, Remerciements

## 🎯 Templates Canva spécifiques à chercher

### Option 1 : Template "Tech Presentation" ou "Startup Pitch"
- **Pourquoi** : Design moderne, adapté aux projets web
- **Couleurs** : Fond sombre (noir/gris foncé) avec accents colorés (bleu, vert, orange)
- **Style** : Minimaliste, beaucoup d'espace blanc

### Option 2 : Template "Portfolio Presentation" ou "Project Showcase"
- **Pourquoi** : Parfait pour présenter un projet étudiant
- **Couleurs** : Moderne, professionnel
- **Style** : Élégant mais pas trop formel

### Option 3 : Template "Modern Business" ou "Corporate Modern"
- **Pourquoi** : Professionnel mais avec un côté moderne
- **Couleurs** : Bleu/gris avec touches de couleur
- **Style** : Équilibré entre sérieux et créatif

## 💡 Conseils pour adapter le template

### 1. Cohérence visuelle
- Utilise **2-3 couleurs maximum** dans toute la présentation
- Suggestions de palette :
  - **Option A** : Noir/Gris foncé + Bleu vif + Blanc
  - **Option B** : Gris foncé + Orange/Vert + Blanc
  - **Option C** : Bleu foncé + Cyan + Blanc

### 2. Typographie
- **Titre** : Police bold, grande taille (36-48pt)
- **Corps** : Police lisible, taille moyenne (18-24pt)
- **Évite** : Polices trop fantaisistes ou difficiles à lire

### 3. Espacement
- **Beaucoup d'espace blanc** pour aérer
- **Maximum 5-6 points** par diapositive
- **Taille de texte** : Lisible depuis le fond de la salle

### 4. Visuels
- **Icônes** : Utilise des icônes simples pour les technologies
- **Schémas** : Utilise des flèches et des formes simples pour le flow
- **Évite** : Trop d'images décoratives qui distraient

### 5. Animations (optionnel)
- **Transitions simples** : Fade ou Slide
- **Animations d'apparition** : Pour les listes à puces
- **Évite** : Animations trop flashy qui distraient

## 🔍 Étapes pour trouver le bon template

1. **Va sur Canva.com** → Créer un design → Présentation
2. **Dans la barre de recherche**, tape un des mots-clés ci-dessus
3. **Filtre par** :
   - Style : Moderne, Minimaliste
   - Couleur : Sombre ou Professionnel
   - Nombre de diapositives : 8-10 (tu peux supprimer les diapos en trop)
4. **Prévisualise** plusieurs templates
5. **Choisis celui qui** :
   - A un fond sombre ou professionnel
   - Est facilement lisible
   - A de l'espace pour tes contenus
   - Correspond au style tech/web

---

## 📝 Checklist avant la présentation

- [ ] Toutes les 8 diapositives sont remplies
- [ ] Le texte est lisible (assez grand, bon contraste)
- [ ] Les couleurs sont cohérentes dans toute la présentation
- [ ] Pas de fautes d'orthographe
- [ ] Les schémas/flux sont clairs
- [ ] Le timing est respecté (5 minutes)
- [ ] Teste la présentation sur l'écran de la salle si possible
